# OnaFlix Frontend

React frontend for the OnaFlix movie streaming platform.

## Stack

- **Framework:** React 19
- **Build:** Vite
- **Styling:** Tailwind CSS
- **Routing:** React Router v7
- **Testing:** Vitest

## Setup

```bash
npm install
npm run dev
```

The app runs at `http://localhost:5173` and expects the API at `http://localhost:3001`.

## Testing

```bash
npm test
npm run test:coverage
```
